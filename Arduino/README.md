# Arduino Code

This folder contains the Arduino firmware used in the GC-AID project.

The Arduino communicates with the Python application through serial communication and controls connected home automation devices such as LEDs and fans.

## Functionalities
- Receives commands from the Python application.
- Controls LED lighting.
- Controls fan operation.
- Supports serial communication between the computer and Arduino.

## Hardware
- Arduino UNO
- LED
- DC Fan
- Transistor-based fan control circuit

## Communication
Serial communication is used to transmit control commands between the Python application and Arduino.
